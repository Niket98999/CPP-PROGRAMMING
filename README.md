# CPP-PROGRAMMING

C++ practice programs written while learning the language in my first semester.

## Files

| File | Topic |
|---|---|
| `all.cpp` | Nested loops printing every pair from 1 to 3 |
| `all (by break).cpp` | Same nested loops, using `break` to exit the inner loop when both counters are equal |
| `all (by continue).cpp` | Same nested loops, using `continue` to skip the pair when both counters are equal |
| `all (6).cpp` | Pattern printing - alphabet pyramid (A, ABC, ABCDE ...) using nested loops |
| `ENTER DIGIT GET DAY.cpp` | Prints the day name for a number 1-7 using `switch-case` |
| `subject marks and per.cpp` | Reads marks of 5 subjects, calculates percentage and prints the grade |
| `while loop prime number.cpp` | Checks whether a number is prime |
| `display prime number from m to n.cpp` | Prints all prime numbers between two numbers m and n |
